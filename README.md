# 1.1.1.1 for iPad

Encrypt all DNS traffic on an iPad (or iPhone) with Cloudflare's 1.1.1.1 resolver, using
DNS over HTTPS or DNS over TLS. It does the same job as the DNS-only mode of Cloudflare's 1.1.1.1 app.

You can set it up two ways:

| | What it is | What you need |
|---|---|---|
| **A. Configuration profile** (easiest) | A `.mobileconfig` file you install from Safari | Just the iPad |
| **B. The OneOneVPN app** | A SwiftUI app that installs the same settings through Apple's `NEDNSSettingsManager` API, with an on/off status screen | A Mac with Xcode and a paid Apple Developer account |

## A. Install a profile (no app needed)

1. Publish the page: in the repo on GitHub, go to **Settings → Pages**, choose
   *Deploy from a branch*, then pick your branch and the `/docs` folder.
   (Or open a file below on github.com in Safari on the iPad and tap **Download raw file**.)
2. On the iPad, open the page in **Safari** and tap a profile. Tap **Allow**.
3. Open **Settings → Profile Downloaded → Install**.
4. To check it worked, visit <https://one.one.one.one/help/>. It should say *Using DNS over HTTPS (DoH): Yes*.

| Profile | Blocks | HTTPS | TLS |
|---|---|---|---|
| 1.1.1.1 | nothing | [standard-https](docs/profiles/1.1.1.1-standard-https.mobileconfig) | [standard-tls](docs/profiles/1.1.1.1-standard-tls.mobileconfig) |
| Families: Malware (1.1.1.2) | malware, phishing | [malware-https](docs/profiles/1.1.1.1-malware-https.mobileconfig) | [malware-tls](docs/profiles/1.1.1.1-malware-tls.mobileconfig) |
| Families: Malware + Adult (1.1.1.3) | the above plus adult content | [family-https](docs/profiles/1.1.1.1-family-https.mobileconfig) | [family-tls](docs/profiles/1.1.1.1-family-tls.mobileconfig) |

To remove a profile: **Settings → General → VPN & Device Management →** pick the profile **→ Remove Profile**.

The profiles are generated by `python3 tools/make_profiles.py`. Edit that script and run it again; don't edit the files by hand.

## B. Build the app

```sh
brew install xcodegen
cd app
xcodegen generate        # creates OneOneVPN.xcodeproj
open OneOneVPN.xcodeproj
```

In Xcode, select the **OneOneVPN** target, then **Signing & Capabilities**. Pick your team and give the app a
unique bundle ID. The **Network Extensions → DNS Settings** capability is already in
`OneOneVPN.entitlements`, and it needs a paid developer account. Plug in the iPad and press Run.

Using the app:

1. Choose a resolver (standard, malware, or malware + adult) and a protocol (HTTPS or TLS), then tap **Install 1.1.1.1**.
2. iOS requires the user to switch it on: go to **Settings → General → VPN & Device Management → DNS** and choose **1.1.1.1**.
3. Return to the app. It should show **Connected**.

The CI workflow (`.github/workflows/build.yml`) builds the app for the iOS simulator and checks the profiles on every push.

## Is this a VPN?

Not a full one. It encrypts your **DNS lookups**, so your ISP or the Wi-Fi network can't read or change which
sites you look up. The rest of your traffic still goes directly to the sites you visit, and they still see your IP
address. Cloudflare's own app calls this mode "1.1.1.1".

If you want a full tunnel (Cloudflare's **WARP** mode), install the official
[1.1.1.1 app from the App Store](https://apps.apple.com/app/id1423538627) and switch on WARP. WARP runs on
Cloudflare's own servers and needs their account system, so a third-party app can't offer it.
